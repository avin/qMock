# Дашборд

Дашборд — это отдельная страница, которую dev-сервер Vite отдаёт по адресу
**`/__apiMocks`**, например `http://localhost:5173/__apiMocks`. Именно здесь
оверрайды становятся активными сценариями.

## Устройство

- **Каталог** показывает ваши оверрайды деревом, повторяющим папки в
  `src/mocks/overrides`. Группы можно раскрывать, а ещё доступен поиск.
- Список **Active** содержит оверрайды, действующие в данный момент.

## Активация сценария

1. Найдите оверрайд в каталоге (раскройте папки или воспользуйтесь поиском).
2. Перетащите его в **Active**.
3. Перезагрузите страницу или заново вызовите запрос в приложении. Новый ответ
   применяется сразу.

## Настройка параметров

Нажмите кнопку-**шестерёнку** на активной строке, чтобы открыть её параметры.
Булевы значения — это чекбоксы, строки — текстовые поля, а строки с `options` —
выпадающие списки. Значения по умолчанию берутся из объявления `params`
оверрайда.

## Включение, выключение и удаление

- **Чекбокс** на активной строке включает или выключает сценарий. Выключенные
  записи **остаются в списке и сохраняют свои параметры**, так что позже их можно
  включить обратно.
- Чтобы полностью убрать сценарий, **перетащите строку обратно в каталог**.

## Порядок имеет значение

Активные оверрайды выполняются **сверху вниз**. Каждый получает ответ, который
выдали вышестоящие. Перетаскивайте строки, чтобы менять порядок.

Конкретный пример на двух оверрайдах, которые оба меняют `GET /api/demo`:

```ts [overrides/sequence/first.ts]
export default defineMockOverride({
  name: 'Append A',
  override: () => ({
    'GET /api/demo': body => ({ ...body, sequence: `${body?.sequence ?? ''}A` }),
  }),
});
```

```ts [overrides/sequence/second.ts]
export default defineMockOverride({
  name: 'Append B',
  override: () => ({
    'GET /api/demo': body => ({ ...body, sequence: `${body?.sequence ?? ''}B` }),
  }),
});
```

| Порядок в Active          | `GET /api/demo` → `sequence` |
| ------------------------- | ---------------------------- |
| Append A, затем Append B  | `"AB"`                       |
| Append B, затем Append A  | `"BA"`                       |
| Только Append A           | `"A"`                        |

Жизненный вариант: поставьте «Slow response» выше «Server error» или наоборот и
скомбинируйте с сценарием «Admin user». Порядок определяет, кто чей результат
видит.

## Управление с клавиатуры

Ручки перетаскивания доступны с клавиатуры:

1. Сфокусируйте строку.
2. **Пробел** — взять её.
3. **Стрелки** — переместить.
4. **Пробел** — отпустить.
5. **Escape** — отменить перетаскивание.

## Сохранённое состояние

Список активных — включая порядок, флаги включения и параметры — сохраняется в
**`.mock-overrides.json`** в корне Vite и восстанавливается при запуске
dev-сервера.

Решите, что этот файл означает для вашей команды:

- **Личные настройки:** добавьте его в `.gitignore`.
- **Общий пресет:** закоммитьте его, чтобы все начинали с одного и того же
  сценария.

Файл можно переименовать или отключить сохранение опцией `stateFile`. См.
[Конфигурацию](/ru/reference/configuration).

::: tip
Сохранённое состояние дашборда применяется только к dev-серверу. [Тесты](/ru/testing/overview)
его никогда не читают.
:::
