# Изменение ответов

Каждая запись в объекте, который возвращает оверрайд, — это **патч маршрута**.
Патчи бывают разных форм: от «заменить всё» до «поправить одно поле». Эта
страница объясняет их все.

## Виды патчей

| Патч                                      | Поведение                                                              |
| ----------------------------------------- | ---------------------------------------------------------------------- |
| JSON-значение или конверт ответа          | Заменить или добавить ответ                                            |
| `null`                                    | Отключить мок и передать запрос дальше по цепочке middleware           |
| `(body, { request, response }) => answer` | Изменить текущий ответ, синхронно или асинхронно                       |
| Модификатор, вернувший `undefined`        | Оставить текущий ответ                                                 |
| Модификатор, вернувший JSON-значение      | Заменить тело, сохранив метаданные ответа                              |
| Модификатор, вернувший конверт            | Заменить ответ целиком                                                 |

Разберём их по очереди на одном и том же базовом обработчике:

```ts
'GET /api/user': {
  kind: 'mock-response',
  status: 200,
  headers: { 'X-Source': 'mock' },
  body: { id: 'demo', name: 'Demo User' },
},
```

## Заменить или добавить: значение или конверт

Используйте, когда сценарий игнорирует то, что было раньше:

```ts
override: () => ({
  'GET /api/user': { id: 'guest', name: 'Guest' },
  'GET /api/new-route': { hello: 'world' },   // добавление маршрута тоже работает
})
```

Обе записи дают полноценный ответ. Второго маршрута в базовых обработчиках не
было — оверрайд его добавляет.

## Отключить мок: `null`

`null` убирает мок для этого маршрута, и запрос проваливается в middleware и
прокси Vite. Это способ сказать: «в этом сценарии для этого эндпоинта
используй настоящий бэкенд».

```ts
export default defineMockOverride({
  name: 'Real user service',
  override: () => ({
    'GET /api/user': null,
  }),
});
```

## Изменить: функция

Функция получает текущее тело и контекст с `request` и текущим `response`:

```ts
override: () => ({
  'GET /api/user': (body, { request, response }) => {
    // body     → текущее тело (здесь объект)
    // request  → MockRequest (route, url, raw)
    // response → текущие статус, заголовки и содержимое
    return { ...body, seenAt: request.url.pathname };
  },
})
```

Функции могут быть асинхронными, например чтобы добавить задержку:

```ts
'GET /api/user': async body => {
  await new Promise(resolve => setTimeout(resolve, 2000));
  return body;                       // без изменений, но на 2 секунды позже
},
```

### Что значит возвращаемое значение

**Вернуть `undefined` — оставить ответ как есть.** Полезно, когда модификатор
нужен только из-за побочных эффектов или условие решило ничего не менять:

```ts
'GET /api/user': (body, { request }) => {
  if (request.url.searchParams.get('debug') === '1') {
    return { ...body, debug: true };
  }
  // неявный undefined: ничего не меняется
},
```

**Вернуть JSON-значение — заменить тело, сохранив статус и заголовки.** Статус
200 и заголовок `X-Source` из базового обработчика остаются:

```ts
'GET /api/user': body => ({ ...body, name: 'Taylor' }),
```

**Вернуть конверт — заменить ответ целиком.** Используйте, когда нужно ещё и
поменять статус или заголовки либо переключиться между JSON, текстом и
бинарными данными:

```ts
'GET /api/user': () => ({
  kind: 'mock-response',
  status: 503,
  headers: { 'Retry-After': '30' },
  body: { error: 'Service unavailable' },
}),
```

Хелпер `json(body, status)` — сокращение для конверта, который задаёт только
статус:

```ts
'GET /api/user': () => json({ error: 'Service unavailable' }, 503),
```

## Особые случаи, о которых стоит знать

### Тело может быть `undefined`

Для **новых** маршрутов (добавленных оверрайдом) или маршрутов, **отключённых**
предыдущим `null`, текущего тела нет. Модификаторы получают `undefined`.
Учитывайте это:

```ts
'GET /api/notes': body => [...(body ?? []), { id: 'extra', text: 'Added' }],
```

### Содержимое, не являющееся объектом

Аргумент body предназначен для JSON-объектов. Если текущий ответ — текст или
байты либо вам нужны статус и заголовки, используйте `context.response`:

```ts
'GET /api/user': (body, { response }) => {
  if (response.status !== 200) return;   // ответы с ошибками не трогаем
  return { ...body, verified: true };
},
```

### Смена типа ответа

Когда JSON-ответ превращается в текст или бинарные данные (или наоборот),
возвращайте полный конверт. Голое значение заменяет только JSON-тело.

```ts
'GET /api/report': () => ({
  kind: 'mock-response',
  headers: { 'Content-Type': 'text/csv' },
  text: 'id,name\n1,Taylor\n',
}),
```

### Настоящий JSON `null`

Поскольку `null` отключает мок, используйте `json(null)`, когда `null` — это
нужное вам тело:

```ts
'GET /api/current-user': json(null),
```

## Наложение

Поскольку каждый активный оверрайд передаёт результат следующему, небольшие
модификаторы хорошо комбинируются. Три оверрайда в таком порядке:

1. **Admin user**: `body => ({ ...body, role: 'admin' })`
2. **Slow**: `async body => { await sleep(2000); return body; }`
3. **Maintenance**: `() => json({ error: 'Maintenance' }, 503)`

Запрос ждёт 2 секунды, а итоговый ответ — 503. Отключите **Maintenance** — и
получите медленного администратора, без единого изменения кода.
