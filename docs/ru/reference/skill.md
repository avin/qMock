# Навык для агента

QMock поставляется с навыком (skill) `qmock`, который помогает кодинг-агентам
(Cursor, Claude Code и другим, читающим папки навыков) подключить QMock и писать
сценарии в вашем проекте.

## Установка

```sh
npx qmock install-skills
```

Выберите директорию навыков другого агента через `--target`:

```sh
npx qmock install-skills --target .claude/skills
```

Директория назначения по умолчанию — `.agents/skills`. Установка **отказывается
перезаписывать** существующий навык, поэтому при обновлении сначала удалите
старую копию.

## Что он покрывает

- Интеграцию с Vite
- Обработчики
- Параметризованные оверрайды
- Работу с дашбордом
- Изолированные тесты

## Установка вручную

Навык самодостаточен и не требует других навыков. Скопируйте
`node_modules/@avinlab/qmock/skills/qmock` в директорию навыков вашего проекта.

## Примеры запросов

После установки можно просить агента, например:

- «Добавь QMock в этот проект и замокай эндпоинты `/api/products`.»
- «Напиши оверрайд, из-за которого `GET /api/orders` возвращает 503, со статусом
  в качестве параметра.»
- «Добавь Playwright-тест, проверяющий пустое состояние заказов с помощью QMock.»
